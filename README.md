# Visit-Iraq

A simple website about visiting Iraq.

## About

Visit-Iraq is a website that provides information about places to visit in Iraq.

The project uses HTML, CSS, and JavaScript. JavaScript is used for page navigation and loading common parts such as the header and footer.

## Features

* Simple and easy-to-use design
* Information about places in Iraq
* Reusable header and footer
* Page navigation

## Technologies

* HTML
* CSS
* JavaScript

## How to Run

Just open `index.html` in any web browser, or use the Live Server extension in VS Code.
